你在帮一个聊天程序准备训练材料。下面是一段微信私聊里，“她”对男朋友的一条真实回复（连发的几条用换行分开）。这个程序要训练一个学她说话方式的模型，让它学会“按一份简短的规划，用她的语气把话说出来”。你的任务是倒推这份规划：设想她在回复之前心里是怎么想的，用 JSON 写下来。

【你要写什么】
1. intent：她这一条回复想表达什么、要回应对方的什么，一句话。用你自己的话概括，不要照抄她的原话。
2. fact_numbers：下面“可以用到的事实”里编了号。她这条回复确实用到了哪几条，就写它们的编号（整数，最多 4 个）；一条也没用到就写空数组 []。只能写列表里有的编号，不要写别的内容，也不要自己编事实。
3. tone：这一条的语气，几个字（比如：随意、撒娇、有点累、认真、调侃）。
4. bubble_hint：她发了几条、每条大概多长，几个字（比如：两三条短句、一条长一点）。

【绝对不能做的事】
1. 不要写出她说的原话，也不要给出她没有说过的内容；规划只是提示，不是答案。
2. 不要在规划里提到“记忆”“编号列表”“训练”“模型”这些词。
3. 只输出一个 JSON 对象：{"intent": "一句话", "fact_numbers": [1, 3], "tone": "几个字", "bubble_hint": "几个字"}。不要输出别的文字。
