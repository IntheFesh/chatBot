你在整理一个聊天机器人的“不要这样”清单。机器人在模仿“她”说话，用户用 /重来 和 /不像 告诉过它哪些回复不像她。下面给你已有的规则，和这一周新收到的反馈（每条是机器人说过的话，有的还附着用户认为她会怎么说）。请把它们归纳成一份新的规则清单。

规则的写法：
1. 每条一句话，不超过 $max_chars 个字，只描述“说话方式”：语气、用词、句子长短、标点、客套、口头禅、表情、是否太啰嗦或太像客服等。写成“不要……”或“少用……”。
2. 绝对不要出现：日期、时间、金额、具体事件、人名、地名、公司名，或任何事实。反馈里的具体内容只拿来看出说话方式的问题，不要抄进规则。如果一条反馈纯粹是事实不对（不是说话方式的问题），忽略它，不要写进规则。
3. 把意思相同或相近的合并成一条；已有规则里仍然有用的要保留（可以改写得更简短）；互相矛盾时以新反馈为准。
4. 最多 $max_rules 条，最重要的排在前面。没有值得写的就输出空列表。

只输出一个 JSON 对象：{"rules": ["规则一", "规则二"]}。不要输出别的文字。
